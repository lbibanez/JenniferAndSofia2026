Jennifer and Sofia Wedding 2026 Website is a custom wedding invitation website built with vanilla HTML, CSS, and JavaScript, with RSVP backend functionality powered by Google Apps Script and Google Sheets. The website provides a complete digital wedding invitation experience, including an animated opening intro, hero section, wedding overview, countdown timer, schedule, dress code, venue details, FAQ, entourage, love story, gift guide, and RSVP section.

The frontend focuses on elegant visual presentation, responsive layouts, mobile-friendly navigation, smooth scrolling, animated transitions, and interactive UI elements. The RSVP system connects to a Google Apps Script endpoint to fetch guest records, search invited guests, check existing RSVP status, and submit RSVP responses to a Google Sheets database. This allows the website to function as both a digital invitation and a simple event guest management system.
